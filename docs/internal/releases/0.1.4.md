# Astris 0.1.4

Release date: 2026-02-21

## Highlights

- Added first provider deployment flow with `astris deploy` for Cloudflare Pages.
- Added `pyproject.toml` configuration support for build/deploy options and environment variables.
- Added clean URL static build mode for extensionless routes in production.

## What's changed

### Added
- Added CLI command `astris deploy`.
- Added Cloudflare Pages deploy integration through `npx wrangler pages deploy`.
- Added parsing for `[tool.astris]` in `pyproject.toml`:
	- `[tool.astris.build]` (`output_dir`, `clean_urls`)
	- `[tool.astris.deploy]` and `[tool.astris.deploy.cloudflare]`
	- `[tool.astris.env]`
- Added public deployment docs at `docs/user/deployment.md`.
- Added tests for CLI config-based build/deploy behavior.
- Added tests for clean URL build output and route rewriting.

### Changed
- Updated package version metadata to `0.1.4`.
- Updated static site build to support folder-based clean URLs (`/about` -> `about/index.html`).
- Updated internal link rewriting to generate extensionless links when clean URLs are enabled.
- Updated `astris new` scaffold to include a starter `pyproject.toml` with Astris settings.
- Updated scaffold dependency management to UV-first (`pyproject.toml`) and removed generated `requirements.txt`.

### Fixed
- Fixed deployment URL shape for Cloudflare Pages by avoiding `.html` route exposure when clean URLs are enabled.

## Why this matters

- Simplifies deployment with a single command (`astris deploy`) for Cloudflare Pages.
- Keeps configuration centralized in `pyproject.toml` for build, deploy, and environment variables.
- Improves production URL quality with extensionless routes.

## GitHub release body (copy/paste)

Astris 0.1.4 introduces first-class deployment support for Cloudflare Pages and clean URL static output.

### Added
- `astris deploy` CLI command (Cloudflare Pages via Wrangler).
- `[tool.astris]` config in `pyproject.toml` for build/deploy/env settings.
- Public deployment guide (`docs/user/deployment.md`) with CLI and Git-based Cloudflare workflows.

### Changed
- Optional clean URL mode in static build (`/about` served from `about/index.html`).
- Internal link rewriting now supports extensionless links in clean URL mode.
- `astris new` now includes a starter `pyproject.toml` with Astris configuration.
- `astris new` now manages dependencies via `pyproject.toml` for UV workflows instead of generating `requirements.txt`.

### Fixed
- Avoided `.html` route exposure in Cloudflare deployments when clean URL mode is enabled.
