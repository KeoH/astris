# Astris 0.1.4

Release date: TBD

## Highlights

This release expands the HTML wrapper API in `astris.lib`, improves HTML output correctness for void elements, and adds read-only JSON content collections.

## What's changed

### Added
- Added wrappers for the modern standard HTML tag set in `astris.lib`.
- Added English class docstrings for HTML wrappers in `astris.lib`.
- Added `astris.content` helpers for JSON content collections.
- Added support for generating static detail pages from JSON entries using template callables/classes.
- Added read-only JSON endpoints in development with configurable per-collection prefixes.

### Changed
- Updated `Element.render()` to render void elements without closing tags.
- Updated user docs to include `astris.lib` in API reference and wrapper notes.
- Updated tests to cover wrapper availability, docstrings, and void rendering.
- Moved layout helpers (`Container`, `Column`, `Row`) into `astris.layout`.
- Updated package exports and API docs to include JSON collection types and helpers.

## Why this matters

- Developers can compose pages with a much broader built-in HTML wrapper set.
- Generated HTML is now closer to standard output for void elements.
- API docs now expose tag wrapper classes directly.
- Content-driven sites can load JSON files as structured collections and publish pre-rendered detail pages.
