# Astris 0.1.3

Release date: TBD

## Highlights

This release adds JSON content collections, expands HTML wrapper coverage, and keeps release tooling improvements introduced in 0.1.3.

## What's changed

### Added
- Added runtime version export as `astris.__version__` in the public API.
- Added workspace agent skill `release-prep-astris` under `.agent/skills/`.
- Added reusable release-prep resources: checklist and release notes template.
- Added wrappers for the modern standard HTML tag set in `astris.lib`.
- Added English class docstrings for HTML wrappers in `astris.lib`.
- Added `astris.content` helpers for JSON content collections.
- Added support for generating static detail pages from JSON entries using template callables/classes.
- Added read-only JSON endpoints in development with configurable per-collection prefixes.

### Changed
- Updated package version metadata to `0.1.3`.
- Updated API docs to include `__version__`, `JsonCollection`, `JsonCollectionEntry`, and `register_json_collection` in the public reference.
- Updated `README.md` and user docs with JSON content collection usage examples.
- Updated `Element.render()` to render void elements without closing tags.
- Moved layout helpers (`Container`, `Column`, `Row`) into `astris.layout`.
- Updated tests to cover wrapper availability, docstrings, void rendering, and JSON collection behaviors.

## Why this matters

- Tooling and users can introspect the installed version directly at runtime.
- Release preparation is now standardized and repeatable for future versions.
- Developers can compose pages with a broad built-in HTML wrapper set.
- Content-driven sites can load JSON files as structured collections, publish pre-rendered detail pages, and query content from read-only dev endpoints.
