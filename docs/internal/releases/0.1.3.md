# Astris 0.1.3

Release date: 2026-02-19

## Highlights

This patch release introduces a runtime version export and adds a reusable workspace skill to standardize future release preparation.

## What's changed

### Added
- Added runtime version export as `astris.__version__` in the public API.
- Added workspace agent skill `release-prep-astris` under `.agent/skills/`.
- Added reusable release-prep resources: checklist and release notes template.

### Changed
- Updated package version metadata to `0.1.3`.
- Updated API docs to include `__version__` in the public reference.
- Updated `README.md` with the workspace skill usage section.

## Why this matters

- Tooling and users can introspect the installed version directly at runtime.
- Release preparation is now standardized and repeatable for future versions.
