# Astris 0.1.2

Release date: 2026-02-19

## Highlights

This patch release adds typed-package metadata for mypy compatibility, introduces a simple API to register CSS/JS assets in the document head, and improves developer workflow with a dedicated `astris build` CLI command.

## What's changed

### Added
- Added `astris/py.typed` to mark the package as typed (PEP 561).
- Added head asset registration APIs in `AstrisApp`: `add_head_link(...)` and `add_head_script(...)`.
- Added `astris build` CLI command to generate static output from `main.py` by default, with optional `--file` support for alternate entry files.

### Changed
- Updated packaging configuration to include `py.typed` in distributed artifacts via `tool.setuptools.package-data`.
- Fixed consumer-side mypy warning: `Skipping analyzing "astris": module is installed, but missing library stubs or py.typed marker`.
- Updated page rendering/build flow to inject registered CSS/JS assets into the document `<head>`.
- Updated `README.md` and `example.py` with CDN usage examples (Bootstrap).
- Updated CLI docs and quickstart examples to use `astris build`.
- Updated `make build` to use `uv run astris build --file example.py`.
- Pinned docs dependencies to keep a stable MkDocs + Material toolchain (`mkdocs>=1.6,<2` and `mkdocs-material>=9.5,<9.6`).

## Why this matters

- Type checkers now recognize Astris as a typed package in downstream projects.
- Users can quickly attach framework styles/scripts (for example Bootstrap or Tailwind via CDN) without manually editing raw HTML.
- Users now get a first-class CLI workflow for static builds (`astris build`) without custom `sys.argv` handling.
- Documentation builds are now stable and free from compatibility warnings in the current toolchain.

## Validation

- `uv run --group dev pyright` -> `0 errors`
- `uv run --group dev pytest` -> `25 passed`
- `uv sync --group docs && make docs` -> strict docs build succeeds.

## Upgrade notes

No migration is required. Existing apps continue to run as-is, and head assets are opt-in.
