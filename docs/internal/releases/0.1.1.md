# Astris 0.1.1

Release date: 2026-02-18

## Highlights

This patch release improves typing ergonomics for component composition and adds automated type-checking in CI.

## What's changed

### Added
- Added `pyright` to the `dev` dependency group.
- Added Pyright configuration in `pyproject.toml`.
- Added a dedicated `typecheck` job in `.github/workflows/tests.yml`.

### Changed
- Updated `Element.__init__` typing for `children` to accept `Sequence[Component | str] | None`.
- Preserved internal `children` storage as `List[Component | str]` (materialized with `list(children)`) to keep runtime behavior unchanged.

## Why this matters

This resolves common Pyright/Pylance false-positive errors when passing homogeneous child lists such as `children=[Div(...)]`.

## Validation

- `uv run --group dev pyright` -> `0 errors`
- `uv run --group dev pytest` -> `17 passed`

## Upgrade notes

No runtime migration is required. Existing code continues to work as-is.
